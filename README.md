# Agência de Voos - Fase I

Projeto desenvolvido em Java para a Fase I do TP, com foco no CRUD de clientes e persistência em arquivo binário.

## Requisitos
- Java 21 ou superior.

## Execução
No Eclipse, importe a pasta como projeto Java/Eclipse e execute a classe `Principal`.

Pelo terminal, a partir da pasta do projeto:

```text
javac -d out src/*.java
java -cp out Principal
```

O sistema cria automaticamente a pasta `dados/clientes` e o arquivo binário `clientes.db` na primeira execução.
